# EIP-7976 — Calldata floor

> **At public launch:** runnable on Amsterdam on the hosted MCP (free; opens launch week 5–9 Oct 2026). Website twin: [exploration](https://feelyourprotocol.org/eip-7976-calldata-floor-cost).

## What became possible

**When does calldata cost 64 gas per byte, and when does a normal call still pay 4 and 16?** On Glamsterdam a transaction that mostly carries data pays 64 gas for every calldata byte, zero or not. A call that does enough work keeps the ordinary price: 4 gas per zero byte and 16 per nonzero byte. Fusaka is the same rule at 10 per zero byte and 40 per nonzero byte. Zero bytes are the ones that jump.

The MCP server runs **your** transaction. It does not ship demo transactions.

Access-list bytes pay that same 64 gas rate (EIP-7981). That rule is already on when you run under Glamsterdam. This verb does not take an access list, so leave `7981` out of `eips`.

## What you can ask your agent

Once the public MCP is live ([Connect](/use/connect)), try prompts like:

- _“This calldata is mostly zeros. What does it cost on Glamsterdam versus Fusaka?”_
- _“This call does real work. Does it still pay 4 and 16 per byte?”_
- _“My gas limit covers execution but not the floor. Is the transaction invalid before it runs?”_
- _“An empty calldata call to an existing account — does the floor add anything?”_

These are **inspiration prompts** — curiosity, understanding, or builder checks.

## What the server does

| Step | Action | Purpose |
| ---- | ------ | ------- |
| 1 | [Discover support](/use/tools/describe-capabilities) | Confirm the 7976 row; `tools` is `run_transaction` |
| 2 | [Run transaction](/use/tools/run-transaction) | Same calldata on **`fusaka`** then **`glamsterdam`**; read `gasUsed` |

Prefund the recipient when it should already exist, so the run does not also create an account. `gasUsed` is what the sender pays, including the transaction base.

## Fork caveat

Run the **same transaction twice** — **`fusaka`** (baseline), then **`glamsterdam`** (preview). One hundred zero bytes and no other work: **22,000** on Fusaka and **21,400** on Glamsterdam (the per-byte floor rose, and the transaction base moved under EIP-2780). One hundred nonzero bytes: **25,000** on Fusaka and **21,400** on Glamsterdam. An empty call to an existing account stays **15,000** on Glamsterdam — the floor adds nothing.
