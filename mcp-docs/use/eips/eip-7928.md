## What became possible

<LeadQuestion text="What does the block commit to besides state root?" />

EIP-7928 adds a **block-level access list (BAL)**: every balance, nonce, code, and storage touch during block execution, hashed as **`blockAccessListHash`** in the header.

Use **`generate_artifact`** with the same inputs as [Run block](/use/tools/run-block) (1–8 impersonated txs, optional accounts, optional header) on **Glamsterdam** to derive BAL JSON and `hash`. Use **`inspect_artifact`** on a BAL you already have for encoding, canonical order, item cap, and optional hash match — layers A–C, not consensus replay against archive mainnet state.
