# EIP-2780 — Intrinsic transaction gas

> **Status:** **Ready for the public MCP** (not launched). Use the [website exploration](https://feelyourprotocol.org/eip-2780-intrinsic-transaction-gas) today.

## What became possible

**Why does sending ETH to someone else still cost 21,000 gas, while sending it to yourself costs 12,000?** EIP-2780 replaces the flat intrinsic charge with named pieces. A value transfer to an existing account is still 12,000 for the sender, plus 3,000 to touch the recipient, plus 6,000 to move the value. A self-send keeps only the 12,000. A call that moves no value is 15,000. Fusaka charges 21,000 for all three.

The MCP server runs **your** transaction. It does not ship demo transactions.

## What you can ask your agent

Once the public MCP is live ([Connect](/use/connect)), try prompts like:

- _“On Glamsterdam, what does a 1 wei transfer to an existing account cost, compared with Fusaka?”_
- _“What does a self-transfer cost, and a zero-value call to an existing account?”_
- _“Does a contract creation with value cost more execution gas than one without?”_
- _“If gas covers 21,000 but not a new-account charge, is the transaction rejected or included and reverted?”_

These are **inspiration prompts** — curiosity, understanding, or builder checks.

## What the server does

| Step | Action | Purpose |
| ---- | ------ | ------- |
| 1 | [Discover support](/use/tools/describe-capabilities) | Confirm the 2780 row; `tools` is `run_transaction` |
| 2 | [Run transaction](/use/tools/run-transaction) | Same transfer on **`fusaka`** then **`glamsterdam`**; read `gasUsed` |

Prefund the recipient when it should already exist, so the run does not also create an account. A self-send uses the same address for sender and recipient.

## Fork caveat

Run the **same transaction twice** — **`fusaka`** (baseline), then **`glamsterdam`** (preview). A value transfer to an existing account stays **21,000** on both, with no state gas. A self-send drops to **12,000** only on Glamsterdam. A zero-value call drops to **15,000** only on Glamsterdam. The piece names are not separate result fields; the total is `gasUsed`.

Creating a new account still adds state gas. That charge is [EIP-8037](/use/eips/eip-8037), not this split.
