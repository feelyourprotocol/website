## What became possible

<LeadQuestion text="Why does sending ETH to someone else still cost 21,000 gas, while sending it to yourself costs 12,000?" />

EIP-2780 replaces the flat intrinsic charge with named pieces. A value transfer to an existing account is still 12,000 for the sender, plus 3,000 to touch the recipient, plus 6,000 to move the value. A self-send keeps only the 12,000. A call that moves no value is 15,000. Fusaka charges 21,000 for all three.

The MCP server runs **your** transaction. It does not ship demo transactions.

## What the server does

<Steps
  :steps="[
    {
      title: 'Discover support',

Prefund the recipient when it should already exist, so the run does not also create an account. A self-send uses the same address for sender and recipient.

::: warning Fork caveat
Run the **same transaction twice** — **`fusaka`** (baseline), then **`glamsterdam`** (preview). A value transfer to an existing account stays **21,000** on both, with no state gas. A self-send drops to **12,000** only on Glamsterdam. A zero-value call drops to **15,000** only on Glamsterdam. The piece names are not separate result fields; the total is `gasUsed`.

Creating a new account still adds state gas. That charge is [EIP-8037](/use/eips/eip-8037), not this split.
:::
