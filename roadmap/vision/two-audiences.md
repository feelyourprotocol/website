# Two Audiences

People and agents are both the customer. Each one can arrive without the other.

The [two legs](/vision/two-legs) are the surfaces: a textbook, and a lab. This page is who they are for. A researcher, an educator, an integrator, someone in the token community. And an agent that finds the server, judges the result, pays when there is something to pay, and points another agent at it.

<Motto>Can an agent finish this without a human who has read the website?</Motto>

That is the design test. The open server does not answer yes to every part of it. The default we build toward is yes.

## What each one needs

| | People | Agents |
| --- | --- | --- |
| Find | The website, X, an exploration | The probe, a registry, another agent |
| Trust | The brand, the explorations, a known builder | Provenance, a pinned spec, the same answer twice |
| Pay | A [token discount](/monetization/token) later, never a gate | Nothing at launch. Later, an [x402](/concepts/x402) quote on new EIPs, and no dashboard |
| Start | A connect page and a host to paste in | A machine-readable list of what runs, what it costs, and how to pay |

## Where this shows up

<IconNote icon="spark" title="Open server">

The hosted door is open, with an honest Glamsterdam catalogue. [x402](/concepts/x402) comes with the paid tier a few weeks later. Agents finding each other is the direction from here.

</IconNote>

<IconNote icon="split" title="Two legs">

The website teaches. The server runs. Same engine, two surfaces.

</IconNote>

<IconNote icon="token" title="The token">

A discount on the paid tier, once that tier exists. Never a key to the door.

</IconNote>

Finding the server, quoting a price, and getting an agent started are part of the product. [Principles](/vision/principles) names the rule: agents are customers. The [roadmap](/roadmap/roadmap) is where that work sits in time.
